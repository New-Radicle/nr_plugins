# Physical-work primitives

Add these to any archetype with field, lab, plant, or installation work. Each uses one of the four physical modes (see `frameworks/references/ai-modes.md`): Edge, Capture, Analyze, Excluded.

| Primitive | Mode | What AI does | What stays human |
|---|---|---|---|
| Field data capture | Capture | Turns voice notes, photos, and forms into structured records | The observation |
| Maintenance and service logs | Capture | Structures the log, flags missing fields, suggests next actions | The work and the judgment |
| Safety and job-hazard documentation | Edge | Drafts briefings and checklists from site and task inputs | The briefing, the sign-off |
| Permitting packages | Augmentation | Assembles from templates and prior submissions; checks completeness | Accuracy review and submission |
| Site and pilot reports | Edge | Drafts the report from captured data | Findings, recommendations |
| Equipment and materials sourcing | Automation | Searches, compares, drafts RFQs | Selection |
| Warranty and RMA handling | Automation | Drafts claims, tracks status | Escalation decisions |
| Lab notebook structuring | Capture | Structures entries, links to protocols and results | The experiment |
| Test data analysis | Analyze | Trends, anomalies, comparisons to spec | The decision |
| Calibration and drift monitoring | Analyze | Detects drift from logs | The recalibration |
| Installation, driving, soldering, wet lab, line work | Excluded | Nothing | Everything |

## Estimating honestly

Physical modes speed up the paperwork around physical work, not the work. Count only the hours spent on prep, capture, and write-up when estimating savings. Capture primitives start at a 55% success rate because it depends on input quality; revisit after two weeks of field use.
